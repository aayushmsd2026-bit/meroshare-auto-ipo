MeroShare Bot Settings

Change passwords, add family members, and set up email, all without opening GitHub. Everything is encrypted in this browser before it's saved.

Change a MeroShare password

First change it on meroshare.cdsc.com.np, then save the same new password here.

Add or update a person

Saved details can't be read back (GitHub keeps them write-only), so to edit someone, fill in all their details again using the same name.

People the bot applies for

    Email alerts

    Uses a Gmail account to send. You'll need a Gmail app password (Google Account → Security → 2-Step Verification → App passwords), not your normal Gmail password.

    Test run

    Logs in to every account and checks open issues without applying. The result is emailed to you in about 2 minutes.
