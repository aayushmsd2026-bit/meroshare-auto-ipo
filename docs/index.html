Applies on MeroShare for your family, automatically

Welcome

To save settings, this page needs a one-time key from GitHub. You only do this once on each phone or computer.

How to get the key

  1. Tap the button below. GitHub opens. Sign in if it asks.
  2. In Expiration, choose No expiration (or the longest date).
  3. In Repository access, choose Only select repositories and pick meroshare-auto-ipo.
  4. In Permissions, set Actions and Secrets to Read and write.
  5. Tap Generate token, then copy the key. It starts with github_pat_.
Open GitHub to make the key ↗

It stays only on this device. It can save settings but can never read passwords back.

Finish setting up

Just a few steps, and then it runs by itself.

    What it does by itself

    Every day at 10:15 AM it checks MeroShare. On the last day of an IPO or FPO it applies for 10 kitta. For right shares it applies for the full amount. Mutual funds and debentures are skipped. You get an email for each application, and a warning before a password expires.

    Change a password

    First change the password on the MeroShare website or app. Then type the same new password here.
